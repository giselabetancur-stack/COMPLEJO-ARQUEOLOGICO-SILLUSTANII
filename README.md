# Sillustani Videos

## Descripción del proyecto

Sillustani Videos es un sitio web informativo y audiovisual dedicado a mostrar la riqueza histórica, cultural y turística del complejo arqueológico de Sillustani, ubicado en la región de Puno, Perú.

El sitio permite conocer la historia de las chullpas, explorar una galería de imágenes y videos, consultar información para visitar el lugar y conocer noticias relacionadas con su cultura y turismo.

## Objetivo

Desarrollar una página web dinámica, moderna y adaptable a diferentes dispositivos, que permita difundir el patrimonio cultural de Sillustani mediante contenido visual e informativo.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** diseño visual, colores, distribución y adaptación a dispositivos.
- **JavaScript:** interactividad, buscador, menú y funcionalidades dinámicas.

## Funcionalidades

- Navegación entre las diferentes secciones.
- Buscador de videos.
- Galería de imágenes y contenido audiovisual.
- Formulario de contacto con validación.
- Diseño adaptable a computadoras, tabletas y celulares.
- Elementos interactivos desarrollados con JavaScript.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. También se puede utilizar la extensión Live Server de Visual Studio Code.
